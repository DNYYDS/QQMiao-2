# QQ文本改写助手 (QQMiaoAssistant)

基于 Android **无障碍服务（Accessibility Service）** 的 QQ 文本改写 / 润色工具。

## 功能（v1.47）

### 文本改写
- **替换规则**：任意「原词=替换词」规则（也支持 `→` / `＝`），可配多条、按顺序应用
  - 内置示例：`我=本喵` `你=大人` `傻逼=杂鱼🐟♡` `。= `
- **断句追加**：按标点分句，句末追加自定义文本（默认 `喵~`）
- **句末颜文字**：内置 50+ 个猫咪颜文字，可自定义替换

### 智能表情（按标点）
- 按句末标点（`？` `！` `。`）匹配对应的表情池，让表情跟语气配合

### 表情附加词 —— 颜文字后的小括号 `(词)`
- 可自定义词池，留空则用内置猫娘词池
- **情绪匹配**：正文命中情绪关键词（笑 / 难过 / 晚安 / 谢谢 / 生气 / 爱 / 早安 / 拜拜）时，附加词换成该情绪的专属词池

### 人格（预设风格）
7 套可选人格，一键切换**专属尾巴 + 附加词池**：

| 人格 | 尾巴 | 词池示例 |
| --- | --- | --- |
| 软萌 | `喵~` | 蹭蹭 / 摇尾巴 / 贴贴 / 咕噜噜 |
| 傲娇 | `哼~` | 才 / 笨 / 不理你 / 谁要你 |
| 高冷 | `……` | 嗯 / 知道 / 随意 / 淡定 |
| 撒娇 | `呜呜~` | 要抱抱 / 人家要嘛 / 委屈巴巴 |
| 元气 | `！！` | 冲呀 / 好耶 / 出发 / 干饭啦 |
| 病娇 | `嘻嘻~` | 永远在一起 / 不许跑 / 你是我的 |
| 腹黑 | `呵呵~` | 你懂的 / 看你的 / 拿捏 / 套路人 |

> 人格作为"默认基座"：你手动自定义的尾巴 / 词池仍优先，不会被人格覆盖。

### 处理模式
- **标点触发**：打字时在标点处立即处理
- **实时处理**：每输入一个字立即处理
- 所有设置经 `SharedPreferences` 实时自动保存

## 技术栈
- 纯 Android 原生 API（无第三方依赖，未使用 OkHttp 等）
- Java
- Gradle 8.8 / AGP 8.4.2
- minSdk 23 / compileSdk 34

## 构建
```bash
./gradlew assembleDebug
```
产物：`app/build/outputs/apk/debug/app-debug.apk`

## 使用
1. 安装 APK（开启"允许未知来源"）
2. 打开应用 → 开启无障碍服务
3. 配置替换规则 / 断句 / 颜文字 / 人格 → 保存设置
4. 在 QQ 聊天中输入，触发规则自动改写
